# Lumina

Weiche Partikel und Rauch im Browser.

**Live:** https://markovigele.github.io/lumina/

![Lumina](docs/lumina.png)

## Start

```bash
npm install
npm run dev
```

Dann http://127.0.0.1:45219 — auf dem Mac: `Lumina starten.command`.

Oder einfach den Live-Link öffnen, ohne Installation.

## In der Anwendung

Ziehen mit der Maus bewegt das Feld. Die Seitenleiste stellt Form, Schwarm und Farben ein.

| Taste | Wirkung |
| --- | --- |
| `Leertaste` | Pause |
| `H` | Seitenleiste ein- oder ausblenden |
| `R` | zurücksetzen |
| `C` | Bild leeren |
| `X` | zufällige Werte |
| `1`–`7` | Werkzeug (anziehen, abstoßen, werfen, schneiden, explodieren, heilen, malen) |
| `[` `]` | Pinsel kleiner oder größer |
| `Ctrl`/`Cmd`+`Z` | rückgängig |
